# EZ-Mall Admin Portal

Internal command center for the EZ-Mall marketplace. Built with the same Vite + React + Tailwind stack as `vendor_fe`.

## Run locally

```bash
cd admin_fe
npm install
npm run dev
```

The app serves on [http://localhost:5175](http://localhost:5175).

## What’s live

- **Dashboard** — marketplace pulse, attention queue, GMV trend, vendor pipeline, live orders.
- **All other routes** — coming-soon shells so navigation and information architecture are in place.

## Stack

Vite, React 19, React Router 7, Redux Persist, TanStack Query, Axios, Recharts, Formik + Yup, Lucide, Sonner, Tailwind 4.
